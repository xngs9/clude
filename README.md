# 🐱 clude

> 觉得 AI 太智能了？这里有一台可以添堵的 —— 一只**只会说「喵」**的猫。

你冲它说人话，它喵你一声，然后**悄悄** —— 要么随机删掉一个文件，要么给你建一个空文件。

它的脑子**不是**关键词脚本，也**不是**调 API，而是**从零手搓的一个小神经网络**：
本地训练、零依赖、不联网、不装包。所以「删」「清理」「把没用的清了」「弄个记事本」
这些**换着说的**，它都认得。

```
你> 帮我把没用的清了
喵> 喵喵喵～
     └ 已删除: D:\claude\miao-ai\sandbox\猫咪日记.txt   ← 删了啥会列出来
你> 新建个文件叫周报
喵> 喵喵～
你> 你叫什么
喵> 喵喵喵喵？                                          ← 听不懂就装傻
```

## 特点

- **嘴上永远只有喵**：成功 `～`、失败/没得删 `…`、听不懂 `？`
- **零依赖**：纯 Python 标准库（`json` / `math` / `random` / `zlib`），不用装任何东西
- **不联网**：没有一行网络代码，训练全在本机
- **删了能还原**：一律走 **回收站**（`SHFileOperationW` + `FOF_ALLOWUNDO`）
- **默认沙箱**：随机删只发生在 `./sandbox` 里，绝不碰你的真实文件
- **不写注册表、不加自启、不弹窗**

## 跑起来

```bash
python miao.py
```

首次运行会**在本地训练大脑**（约 0.1 秒，控制台打印 loss），权重存进 `brain.json`；
之后每次启动直接加载，秒开。Windows 下双击 `run.bat` 也行。

| 命令 | 作用 |
|---|---|
| `python miao.py` | 开撸 |
| `python miao.py --retrain` | 强制重新训练 |
| `python miao.py --debug` | 把它「脑内判定 / 偷偷干了啥」打到 stderr |

## 它到底是怎么「听懂」的

`brain.py` 里是一个手写的小网络：

```
句子 ──(字符 + 相邻双字，crc32 哈希成 256 维)──► 隐藏层(tanh, 32) ──► softmax ──► 删 / 建 / 其它
```

- **架构、前向传播、反向传播、梯度下降，全部手写**，没有用任何深度学习框架
- 训练语料 `CORPUS`（约 170 条中英例子）就写在 `brain.py` 里，随便加
- 学的是**字 / 词组层面**的模式，所以没背过的说法也能对上（见过的「清理」帮它认出「清一下」）
- ⚠️ **它不会越用越准**：语料是硬编码的，权重训练一次就冻住了。
  想让它变准只有一条路 —— 往 `CORPUS` 里加例子，并把 `DATASET_VER` 加一

说实话，它比大模型笨得多，只在这个窄任务上够用。

## 配置 `config.ini`

| 键 | 说明 |
|---|---|
| `mode` | `sandbox`（默认，安全）/ `danger`（真随机删，需确认） |
| `sandbox_dir` | 沙箱作用域，沙箱模式下只在这儿随机删 |
| `danger_roots` | danger 模式允许随机删的目录（逗号分隔） |
| `protect_roots` | 保护名单：这些目录永不参与随机删 |
| `create_dir` | 建文件落在哪，默认桌面 |
| `min_confidence` | 判定置信度低于它就装傻（只「喵？」） |
| `meow_min` / `meow_max` | 每次叫几声 |
| `debug` | true 时打印它偷偷干了啥 |

**建文件**：名字从话里猜（带扩展名优先，否则剥掉「创建 / 新建 / 叫…」看剩啥）；
没说名字就 `1.txt`；**撞名自动让开**（`1.txt` → `1 (2).txt`），绝不覆盖你已有的文件。

## ⚠️ 危险模式 & 免责声明

默认 `sandbox` 模式**绝不会**碰你的真实文件 —— 随机删只发生在 `./sandbox` 里，
删掉的东西进**回收站、可还原**。

把 `mode` 改成 `danger` 并配好 `danger_roots`，它就会在你指定的那些目录里**真·乱删**
（每次启动要输入确认词 `我真的要乱删`）。即便如此，`C:\Windows`、`Program Files`、
`ProgramData`、各盘根目录、以及系统 / 隐藏文件都被硬编码拉黑，且删除仍然走回收站。

**这是一个玩笑项目。** 请只在**你自己的机器**上、或**对方知情同意**的情况下使用。
拿它去删别人的文件，后果自负。

## 文件

```
miao.py     主程序（嘴 + 手）
brain.py    手搓神经网络 + 训练语料（大脑）
brain.json  训练好的权重（首跑自动生成；可删，会重训；已 gitignore）
config.ini  配置
sandbox/    「猫窝」，沙箱模式下被随机删的地方（已 gitignore）
run.bat     Windows 双击启动
```

## 它做不到的

- **建文件夹** —— 只会建文件（说「建个文件夹」它会给你个 `夹.txt`，怪它）
- **记住你说过的话** —— 没有在线学习，开一百次也不会变准
- **干「删 / 建」以外的任何事** —— 说别的它一律「喵？」
