# clude

一只只会说「喵」的命令行玩具：你对它说人话，它回一声喵，然后随机删掉一个文件，或者建一个空文件。

它的意图识别不是关键词匹配，也不是调用大模型 API，而是一个**从零手写的小型神经网络**：
本地训练、零第三方依赖、不联网。因此「删」「清理」「把没用的清了」这类**不同说法**，它都能识别。

```
你> 帮我把没用的清了
喵> 喵喵喵～
     └ 已删除: .\sandbox\猫咪日记.txt       ← 删除的文件会列出来
你> 新建个文件叫周报
喵> 喵喵～
你> 你叫什么
喵> 喵喵喵喵？                              ← 无法识别时只叫一声「喵？」
```

## 特点

- **输出只有喵**：成功 `～`、失败或无可删 `…`、无法识别 `？`。
- **零依赖**：只用 Python 标准库（`json` / `math` / `random` / `zlib`）。
- **不联网**：没有任何网络请求，训练全部在本机完成。
- **删除可还原**：一律走回收站（`SHFileOperationW` + `FOF_ALLOWUNDO`）。
- **默认沙箱**：随机删除只发生在 `./sandbox` 内，不会触碰真实文件。
- **不写注册表、不设自启、不弹窗。**

## 运行

```bash
python miao.py
```

首次运行会在本地训练模型（约 0.1 秒，控制台输出 loss），权重保存到 `brain.json`，
之后启动时直接加载。Windows 下也可以双击 `run.bat`。

| 命令 | 说明 |
| --- | --- |
| `python miao.py` | 直接运行 |
| `python miao.py --retrain` | 强制重新训练 |
| `python miao.py --debug` | 把意图判定和实际执行的动作输出到 stderr |

## 实现

`brain.py` 中的网络结构：

```
输入 ──(字符 + 相邻双字，crc32 哈希为 256 维)──► 隐藏层(tanh, 32) ──► softmax ──► 删 / 建 / 其他
```

- 前向传播、反向传播、梯度下降全部手写，未使用任何深度学习框架。
- 训练语料 `CORPUS`（约 170 条中英文样例）直接写在 `brain.py` 中，可自行扩充。
- 特征基于字和词组，未见过的新说法也能匹配（例如由「清理」推断出「清一下」）。
- 语料硬编码，权重训练一次后固定，**不具备在线学习能力**；要提高准确率只能增加语料，
  并把 `DATASET_VER` 加一以触发重新训练。

## 配置 `config.ini`

| 键 | 说明 |
| --- | --- |
| `mode` | `sandbox`（默认，安全）/ `danger`（随机删除，启动时需确认） |
| `sandbox_dir` | 沙箱目录，沙箱模式下只在此目录内随机删除 |
| `danger_roots` | danger 模式允许随机删除的目录（逗号分隔） |
| `protect_roots` | 保护目录，永不参与随机删除 |
| `create_dir` | 新建文件的位置，默认为桌面 |
| `min_confidence` | 判定置信度低于该值时不做任何操作 |
| `meow_min` / `meow_max` | 每次喵叫的次数区间 |
| `debug` | 为 true 时输出判定结果和实际动作 |

**新建文件**：文件名从语句中推断（优先带扩展名的词，否则去掉「创建 / 新建 / 叫…」后取剩余部分）；
未推断出名字时使用 `1.txt`；**重名时自动递增**（`1.txt` → `1 (2).txt`），不会覆盖已有文件。

## 危险模式与免责声明

默认的 `sandbox` 模式不会触碰真实文件 —— 随机删除仅发生在 `./sandbox` 内，
且被删文件进入回收站，可以还原。

把 `mode` 改为 `danger` 并配置好 `danger_roots` 后，它会**在指定目录内真正随机删除文件**
（每次启动需输入确认词 `我真的要乱删`）。即便如此，`C:\Windows`、`Program Files`、
`ProgramData`、各盘根目录以及系统 / 隐藏文件仍被硬编码排除，删除同样走回收站。

**本项目仅用于娱乐。** 请只在**自己的机器**上、或**对方知情同意**的前提下使用。
将其用于删除他人文件，后果自负。

## 文件

```
miao.py     主程序（输出 + 文件操作）
brain.py    手写神经网络与训练语料
brain.json  训练后的权重（首次运行生成；可删除，会重新训练；已 gitignore）
config.ini  配置
sandbox/    沙箱目录（已 gitignore）
run.bat     Windows 启动脚本
```

## 已知限制

- 只创建文件，**不创建文件夹**。
- 不记忆历史输入，**没有在线学习**。
- 只处理「删除」和「新建」两类意图，其余一律回复「喵？」。
